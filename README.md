# Penguin Data Analysis

## Project Overview

This project analyzes the Palmer Penguins dataset using R and statistical analysis techniques.

The assessment covers:

- Data cleaning and preprocessing
- Exploratory data analysis
- Hypothesis testing
- Correlation analysis
- Simple linear regression
- Multiple linear regression
- Data visualization

## Key Findings

- Gentoo penguins are significantly heavier than Adelie penguins.
- The proportion of male penguins is approximately 50%.
- Flipper length has the strongest positive relationship with body mass.
- The simple regression model explained approximately 75.9% of body\-mass variation.
- The multiple regression model achieved an R² of 0.761.
